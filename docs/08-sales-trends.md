# Phase 8：銷售趨勢

## 目的

- 看每天、每週、每月賣多少，哪些商品在成長或衰退。
- 準備 Phase 10 補貨建議要用的「每日需求」資料。

## 兩種「賣了多少」

| | 怎麼算 | 用在哪裡 |
|---|---|---|
| **售出件數** | 已付款訂單的商品，依付款（下單）日期；組合商品算組合本身、拆盒賣的卡片算卡片 | 銷售走勢、商品排行 |
| **庫存需求** | 實際從庫存拿走的量：一般商品 ＋ 組合商品拆成組成 SKU ＋ 拆盒算盒子；贈品也算（貨真的出去了） | 每週需求、可撐幾週、Phase 10 安全庫存 |

- 只計已付款訂單；未付款、取消、付款失敗都不算。
- 退款不從趨勢扣除（金額變化見損益表）。
- 日期為美東時間，每週從週一開始。
- 還沒對應 SKU 的商品，用 Whatnot 名稱（去掉 #編號）合併顯示，對應後自動歸到 SKU。
- 運送中的庫存**不算**美國可售。

## 畫面（側邊欄 › 銷售趨勢）

**銷售走勢**
- 期間：最近 30 天（每日）、最近 12 週、最近 12 個月。
- 長條圖可以看成交額或件數，滑過任一根長條會顯示件數、訂單、直播場數、每場平均。
- 各商品／各產品／各分類排行：件數、成交額、佔比、走勢小圖。前 12 名以外合併為「其他」。

**商品動向與庫存**
- 最近 N 週（1／2／4／8／12）和再之前同樣長的期間比較，每個 SKU 標示：

  | 標示 | 條件 |
  |---|---|
  | 成長 | 增加 25% 以上 |
  | 衰退 | 減少 25% 以上 |
  | 持平 | 變化在 ±25% 以內 |
  | 新開始賣 | 之前沒有賣 |
  | 停止銷售 | 最近沒有賣 |
  | 量少 | 兩段合計不到 6 件 |

- 每週需求、美國可售、運送中、**可撐幾週**（美國可售 ÷ 每週需求）、12 週需求小圖。
- 撐不到 11 天（供應商交期）的 SKU 會在上方提醒。

## 權限

| | 需要的權限 |
|---|---|
| 件數、需求、庫存 | `orders.view`：所有看得到訂單的人（含日本庫存人員，補貨要用） |
| 金額（成交額） | `finance.view` 或 `finance.view_livestream`；其他人只會看到件數 |

## API

| 端點 | 內容 |
|---|---|
| `GET /api/v1/reports/trends?from&to&granularity=day/week/month&group=sku/product/category` | 銷售走勢 |
| `GET /api/v1/reports/trends/movers?weeks=4` | 商品動向與庫存 |
| `GET /api/v1/reports/trends/skus/{id}?days=90` | 單一 SKU 每日需求、平均、標準差（σ），Phase 10 安全庫存要用 |

## 資料庫變更

無。所有數字即時從訂單、組合商品設定、拆盒紀錄計算，不另存彙總，所以永遠和訂單一致。
