# Phase 7：損益表與營運費用

## 目的

算出公司每週、每月的**淨利**：直播賺的毛利，再扣掉場地、人事、包材等營運費用。

## 損益表（側邊欄 › 損益表，需要 `finance.view`）

全部從帳本（`financial_entries`）依營業日期（美東時間）彙總，可選每週（週一開始）、每月或整段合計：

| 列 | 帳本類型 |
|---|---|
| 商品銷售額 − 優惠券 − 退款 = **淨銷售額** | revenue、sales_discount、refund／refund_adjustment |
| Whatnot 佣金、金流手續費、賣家付的運費 | platform_fee、payment_processing_fee、shipping_cost／shipping_adjustment |
| 商品成本 | cogs、cogs_adjustment（採購批次先進先出） |
| 存貨損耗／盤盈 | inventory_adjustment（[docs/09](09-logistics.md)） |
| **毛利** | |
| 其他收入／支出 | other_income（小費等）、other_expense |
| 營運費用（依類別） | operating_expense |
| **淨利** | |

- **認列時間**
  - 營收：在下單（付款）時認列；商品成本：在出貨時認列。
  - 月底賣出、下個月才出貨的商品，成本會落在下個月。
  - 頁面會列出「還沒出貨的件數」，不會估算。
- **買家付的運費與銷售稅**：不計入營收。
- **數字不完整時**：頁面列出手續費還沒進財務報表的訂單、未出貨件數、需要處理的訂單商品、需要確認的 Whatnot 交易，以及財務報表同步到的時間。
- **匯出明細 CSV**
  - 期間內每一筆帳務紀錄：日期、類型、USD、原幣、匯率、Whatnot 訂單、直播、SKU、費用類別、來源、備註。
  - 給會計使用，Excel 可直接開啟中文。
  - 以 `=`、`+`、`-`、`@` 開頭的文字會加上 `'`，防止試算表公式注入。

## 營運費用（側邊欄 › 營運費用）

- 幣別 USD、JPY、TWD。
  - 外幣匯率的寫法和成本試算表一樣，為「1 USD = N」，例如 150。
  - USD 金額 = 金額 ÷ N；原幣金額、匯率都保存。
- 類別預設 12 種：場地租金、人事薪資、主播／助理費、包材耗材、運費（非 Whatnot 標籤）、廣告行銷、軟體訂閱、設備、差旅、銀行／匯款手續費、會計／稅務、其他。
- **可以指定屬於哪一場直播**（例如主播費），那場的「直播損益」就會顯示這場的營運費用和淨利。
- **收據**：照片（JPEG／PNG／WebP）或 PDF，10 MB 以內；系統依檔案內容判斷格式，不是看副檔名。
- **不能修改、不能刪除**（資料庫觸發器保證）：記錯了按「作廢」並填原因，系統用沖銷分錄撤回，再重新記一筆，兩筆都保留。
- **連按兩次「儲存」只會記一筆**。
- **誰看得到**
  - 有 `finance.view`（管理員、台灣管理人員）：看全部費用。
  - 只有 `expense.create`（美國直播營運）：只看得到自己記的，薪資等不會外流。

## 月結（結帳）

- 在損益表選「每月」，已經結束的月份可以按「結帳」（需要 `period.close`，預設只有管理員）。
- 結帳後那個月的數字不會再變動（資料庫觸發器拒絕任何新分錄）。
- **之後才進來的資料**
  - Whatnot 訂單、出貨成本、手續費等自動入帳：記在**當天**，備註「屬於已結帳的 2026-10，記入 2026-11」。不會遺失，也不會讓同步出錯。
  - 手動費用：不能記入已結帳月份，請記在目前月份。
- 可以「重新開啟」；結帳與重新開啟都有稽核紀錄。
- 本月還沒結束，不能結帳。

## 資料庫變更（0012）

- `expense_categories`（可設定的費用類別，已預設 12 種）
- `operating_expenses` 新增：`fx_quote`、`vendor`、`receipt_content_type`、`idempotency_key`、作廢欄位（`voided_at`、`voided_by`、`void_reason`、`void_entry_id`）
- 觸發器 `erp_expense_guard`：費用不可修改或刪除，只能作廢一次
