Megatokyo ERP － 裝在自己的 Windows 電腦上
==============================================

這台電腦會變成系統的「主機」：只要它開著，您和台灣、日本、美國的同事都能用手機或電腦連進來。
費用：免費（只用到 Docker Desktop 和 Cloudflare 的免費服務）。


【第 1 步】安裝 Docker Desktop（只要做一次）
------------------------------------------------
1. 用瀏覽器打開 https://www.docker.com/products/docker-desktop/
2. 按「Download for Windows」下載。
   下載後對安裝檔按右鍵 →「以系統管理員身分執行」（很重要，否則會出現
   「Virtual Machine Platform ... not enabled」的錯誤）。
   如果問要裝給誰，選「All-users installation」，其他按預設值。
   還是失敗的話：在開始選單搜尋 PowerShell → 右鍵「以系統管理員身分執行」→
   輸入 wsl --install 按 Enter → 跑完重新開機 → 再安裝一次 Docker Desktop。
3. 裝好後「重新開機」。
4. 開機後打開 Docker Desktop：
   - 同意使用條款（Accept）
   - 要您登入或註冊時，可以按「Skip」跳過
   - 等左下角出現綠色的「Engine running」
5. 右上角齒輪（Settings）→ General → 勾選「Start Docker Desktop when you sign in to your computer」
   （這樣電腦重開後系統會自己啟動）


【第 2 步】下載系統
------------------------------------------------
1. 登入 GitHub 網站，打開 https://github.com/zxc24257173dsa-commits/megatokyo
2. 按綠色的「Code」按鈕 →「Download ZIP」
3. 對下載的 ZIP 按右鍵 →「解壓縮全部」，放到例如 C:\megatokyo
   （路徑裡不要有空白或中文比較保險）


【第 3 步】啟動（第一次會自動安裝）
------------------------------------------------
1. 打開資料夾裡的「selfhost」，雙擊「啟動.bat」
   - 如果出現藍色的「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」
2. 第一次大約要 5～15 分鐘（下載和準備系統），請耐心等候。
3. 它會請您輸入：
   - 您的 Email（登入用）
   - 顯示名稱
   - 密碼（至少 12 個字元，輸入時畫面不會顯示，這是正常的）
4. 完成後會自動打開瀏覽器 http://localhost:8080
5. 第一次登入時，系統會顯示一個 QR Code：
   用手機安裝「Google Authenticator」App，掃描它，再輸入 App 上的 6 位數字。
   之後每次用密碼登入都要輸入這 6 位數字（保護您的帳號）。


【第 4 步】連上 Whatnot
------------------------------------------------
1. 登入後到左邊選單「Whatnot 串接」
2. 貼上您的 Whatnot API 金鑰（wn_pat_tk_ 開頭），按「儲存」，再按「測試連線」
3. 之後系統每小時會自動從 Whatnot 同步訂單、出貨和手續費，不用再按。


【第 5 步】讓同事使用
------------------------------------------------
1. 同事用的網址在「網址.txt」裡（長得像 https://xxxx-xxxx.trycloudflare.com），
   用 LINE 傳給同事，手機或電腦打開都可以。
2. 在系統的「使用者」頁幫每位同事建立帳號，選好角色（例如美國同事選「美國直播營運」）。
3. 注意：這台電腦重新開機、或按過「停止」之後，同事的網址會換一個新的。
   請雙擊「顯示網址.bat」查看新網址，再傳給同事。
   （如果之後覺得麻煩，可以改成固定網址，或改租主機，請跟 Claude 說。）


【電腦設定】很重要
------------------------------------------------
- 不要讓電腦睡眠：設定 → 系統 → 電源 → 「螢幕和睡眠」→「接上電源時，讓裝置進入睡眠」選「永不」
- 這台電腦要一直開著、插著電、連著網路。
- 關機或睡眠的時候，大家都會暫時用不了；開機後 Docker Desktop 會自己把系統啟動。


【備份】
------------------------------------------------
- 系統每天自動備份到「selfhost\backups」資料夾，保留 30 天。
- 建議每週把整個 backups 資料夾複製一份到 Google 雲端硬碟或隨身碟，
  這樣這台電腦壞掉時資料也不會不見。
- backups 裡的「金鑰-還原備份時需要-請勿外流.env」是還原時必需的鑰匙，
  請一起保存，但不要傳給別人。


【更新到新版本】
------------------------------------------------
Claude 通知有新版本時：
1. 照第 2 步再下載一次 ZIP，解壓縮後「覆蓋」到原本的資料夾
   （不要刪掉 selfhost 裡的 .env、data、backups，裡面是您的資料和鑰匙）
2. 雙擊「啟動.bat」，系統會自動更新，資料都會保留。


【搬到另一台電腦（例如放到美國那邊）】
------------------------------------------------
系統一次只能開一台。搬家步驟：
1. 新電腦：照第 1 步裝好 Docker Desktop，把系統資料夾（ZIP 解壓縮）放好。
   （新電腦不用先按「啟動」。）
2. 舊電腦：雙擊「做搬家包.bat」，會在 selfhost\backups 裡做出一個 move- 開頭的資料夾。
3. 把整個 move- 資料夾用隨身碟或 Google 雲端硬碟傳到新電腦，
   放進新電腦的 selfhost\backups 資料夾。
   （裡面有系統的鑰匙，不要傳到公開的地方，也不要用 LINE 群組傳。）
4. 新電腦：雙擊「還原搬家包.bat」，輸入 Y 確認。帳號、資料、照片都會搬過去。
5. 新電腦確定可以登入後，舊電腦按「停止.bat」，以後只開新電腦。
6. 在新電腦按「顯示網址.bat」，把新網址傳給大家。
電腦壞掉要換新電腦時，用 backups 裡最新的 move- 資料夾也是一樣的做法；
所以建議定期按「做搬家包.bat」，把最新的 move- 資料夾另外存一份。


【其他按鈕】
------------------------------------------------
- 停止.bat：暫時關掉系統（資料都保留）
- 顯示網址.bat：查看同事用的網址
- 做搬家包.bat／還原搬家包.bat：搬到另一台電腦（見上方說明）


【遇到問題】
------------------------------------------------
把黑色視窗的畫面截圖傳給 Claude 就好。
